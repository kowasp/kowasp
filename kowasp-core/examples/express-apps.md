# Example ExpressJS Applications for XSS Analysis

## 1. E-commerce Applications
- [NodeBB](https://github.com/NodeBB/NodeBB) - Forum software
- [Ghost](https://github.com/TryGhost/Ghost) - Blogging platform
- [KeystoneJS](https://github.com/keystonejs/keystone) - CMS and web application framework

## 2. Authentication & User Management
- [Express-User](https://github.com/madhums/node-express-mongoose-demo) - User authentication demo
- [Express-Mongo-Starter](https://github.com/madhums/node-express-mongoose) - Authentication boilerplate

## 3. API & Backend Services
- [Express-API-Starter](https://github.com/danielfsousa/express-rest-es2017-boilerplate) - REST API boilerplate
- [Express-API-Template](https://github.com/kunalkapadia/express-mongoose-es6-rest-api) - API template with MongoDB

## 4. Real-world Vulnerable Applications
- [OWASP Juice Shop](https://github.com/juice-shop/juice-shop) - Intentionally vulnerable web app
- [DVWA Node](https://github.com/snoopysecurity/dvws-node) - Damn Vulnerable Web App in Node.js

## 5. Production Applications
- [Express-React-Boilerplate](https://github.com/react-boilerplate/react-boilerplate) - Full-stack React/Express app
- [Express-Vue-Boilerplate](https://github.com/express-vue/express-vue) - Express with Vue.js
